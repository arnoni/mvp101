Implement “Minimal make it match Postgres plan v2":

Goal
Move UGC persistence to Neon Postgres as the source of truth while keeping Redis as a short lived helper. Keep code changes minimal and consistent with existing primitives: run_gate, PolicyEngine, QuotaRepository, AreaBucketer, Turnstile verification, and existing DTO patterns.

Hard decisions to enforce
1. Turnstile is mandatory for everyone on UGC submit. No exception for paid tier. No admin bypass for UGC.
2. Evidence URLs are not stored in Postgres for now. Store evidence_urls in Redis keyed by public_id for 7 days.
3. Geo cell quantization stays at about 50m for now. Use the existing approach you already chose and do not change it.
4. Keep returning a UUID to the client. The returned value is public_id.
5. Keep quota gating for UGC using the existing run_gate flow. But ensure Turnstile is always required for UGC regardless of tier.
6. Skip CSRF for UGC. Rely on Turnstile mandatory plus strict content limits plus rate limiting via run_gate.

Database targets
Use existing table public.ugc_reports exactly as currently created:
Columns used for insert at minimum:
public_id uuid default gen_random_uuid()
reporter_anon_id text not null
reporter_user_id bigint null
reporter_tier text not null default free
title text not null
description text not null
category text null
severity smallint null check 1 to 5
geom geography(point,4326) not null
status ugc_report_status default pending
content_hash text not null
geo_cell text not null
created_at default now()
updated_at default now()

Indexes assumed present
geo_cell, created_at desc
content_hash
reporter_anon_id, created_at desc
unique public_id

API behavior to implement
Endpoint: POST /api/ugc/report-submit

Input DTO expectations
UGCReportRequest includes:
title, description, lat, lon, optional category, optional severity, optional evidence_urls list, turnstile_token required
Enforce strict length constraints using Pydantic or explicit checks consistent with current style.

Flow requirements
1. Do not call protect_mutation for this endpoint.
2. Cheap validation first:
Validate bbox using is_inside_da_nang_bbox before any expensive work.
Validate severity is 1 to 5 if provided.
Validate evidence_urls length and count small. Example: max 5 URLs. Each max length 500. If invalid return 400 with ErrorResponse.
3. Compute area_code using AreaBucketer.get_area_code(lat, lon).
4. Gate:
Call run_gate with data_turnstile_token set to provided token.
But for UGC force Turnstile requirement even if policy would not require it.
If token missing or invalid return 403 with ErrorResponse error CHALLENGE_REQUIRED or INVALID_CHALLENGE.
Ensure quota is consumed before any Postgres write.
5. Dedup logic:
Compute geo_cell using 50m quantization exactly as current implementation.
Compute content_hash as sha256 of normalized title description category.
Compute day_bucket as UTC date string YYYYMMDD.
Compute dedup_key as sha256 of reporter_anon_id | geo_cell | content_hash | day_bucket.
Use Redis key ugc:dedup:{dedup_key} with TTL 7 days and NX.
If not claimed, fetch existing public_id from Redis and return ok true duplicate true report_id existing_public_id.
If claimed, proceed.
6. Postgres insert:
Insert one row into ugc_reports with the computed fields.
Do not insert created_at or updated_at. Rely on defaults.
Convert lat lon to geography correctly using:
ST_SetSRID(ST_MakePoint(lon, lat), 4326)::geography
Let public_id be generated by Postgres default OR explicitly pass a generated UUID.
Preferred: explicitly pass a UUID you generate in code so you can reuse it for Redis evidence storage and dedup mapping.
Return the public_id to the client.
7. Evidence URLs in Redis:
If evidence_urls provided, store them in Redis under key:
ugc:evidence:{public_id}
Value JSON list of URLs
TTL 7 days
This should happen after successful Postgres insert.
8. Also store mapping from dedup redis key to public_id:
Set ugc:dedup:{dedup_key} to public_id string
TTL 7 days
This is the dedup fast path.

Code structure constraints
Keep changes minimal and local.
If you need DB access, use request.app.state.db_engine already created in app.main lifespan.
Use SQLAlchemy async engine connection and a text query or core insert. No ORM required.
Add a tiny helper function inside routes.py or a small new repository file, whichever is minimal and clean.
Do not introduce new routers or refactor file structure.

Error handling
Return consistent ErrorResponse objects.
Use 400 for validation errors.
Use 403 for Turnstile required or invalid.
Use 503 if Redis or Postgres is unavailable, with detail “enforcement unavailable” or a specific ErrorResponse error like STORAGE_UNAVAILABLE.
On duplicate, return ok true duplicate true report_id existing_public_id.
On success, return ok true duplicate false report_id public_id.

Deliverables
1. Updated UGCReportRequest DTO definition if needed.
2. Updated /ugc/report-submit endpoint code.
3. Any helper function for computing geo_cell and content_hash and normalization.
4. SQL insert statement used.
5. Quick note on how to query evidence URLs by public_id from Redis.
6. Add or update one small test if you can, focusing on dedup key composition and required Turnstile behavior.

from sqlalchemy import text

UGC_INSERT_SQL = text("""
INSERT INTO ugc_reports (
  public_id,
  reporter_anon_id,
  reporter_user_id,
  reporter_tier,
  title,
  description,
  category,
  severity,
  geom,
  status,
  content_hash,
  geo_cell
)
VALUES (
  :public_id::uuid,
  :reporter_anon_id,
  :reporter_user_id,
  :reporter_tier,
  :title,
  :description,
  :category,
  :severity,
  ST_SetSRID(ST_MakePoint(:lon, :lat), 4326)::geography,
  'pending'::ugc_report_status,
  :content_hash,
  :geo_cell
)
RETURNING id, public_id
""")
